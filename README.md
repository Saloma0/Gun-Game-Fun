# 🏙️ Ruínas Urbanas: FPS 3D (Web Game)

Um jogo de tiro em primeira pessoa (FPS) 3D completo, rodando diretamente no navegador web usando **HTML5, JavaScript e Three.js**. O jogo conta com um cenário pós-apocalíptico de cidade abandonada, sistema de ondas de inimigos, inteligência artificial de perseguição, mini-mapa (radar), sistema de loot/drops e uma loja interativa!

Desenvolvido com **Gemini** e melhorado po **Saloma0**🤖✨

---

## 🎮 Funcionalidades do Jogo

- **Mundo 3D Estilizado:** Cidade abandonada com prédios, destroços, clima ensolarado com nuvens volumétricas e **sistema de colisão rígido** (você não atravessa paredes nem sai do mapa).
- **IA de Inimigos Dinâmica:** Bots com visual tático que patrulham, localizam o jogador e disparam projéteis de energia em tempo real.
- **Mini-Mapa / Radar:** Radar circular em tempo real no canto superior direito mostrando a sua posição e a localização exata dos inimigos ao redor.
- **Sistema de Economia & Loja:** Derrote inimigos para coletar **Coins (Moedas)** e gaste-os no menu principal para comprar munições, kits médicos ou skins exclusivas.
- **Múltiplas Armas & Skins:** Alterne entre Pistola (munição infinita), Rifle de Assalto e Escopeta. Desbloqueie skins lendárias como *Cyberpunk Neon* e *Ouro de Elite*.
- **Áudio Sintetizado:** Efeitos sonoros imersivos gerados via **Web Audio API** nativa (sem necessidade de arquivos externos de áudio).

## 🕹️ Controles

| Tecla / Ação | Ação no Jogo |
| :--- | :--- |
| **W, A, S, D** | Movimentar o personagem |
| **Mouse** | Olhar ao redor / Mirar |
| **Clique Esquerdo** | Atirar |
| **1, 2, 3** | Alternar entre as armas (Pistola, Rifle, Escopeta) |
| **R** | Recarregar arma |
| **E** | Usar Kit Médico (Cura) |

---

## 🚀 Como Jogar

1. Clone ou baixe este repositório para o seu computador.
2. Certifique-se de que o arquivo principal está salvo como `index.html` (ou o nome da sua preferência).
3. Dê um duplo clique no arquivo HTML para abri-lo em qualquer navegador moderno (Google Chrome, Edge, Firefox, etc.).
4. Acesse a loja no menu inicial para gastar seus coins iniciais se quiser, clique em **"INICIAR COMBATE"**, clique na tela para capturar o mouse e divirta-se!

## 🛠️ Tecnologias Utilizadas

- **HTML5 & CSS3** (Interface, HUD, Menu e Estilização)
- **JavaScript (ES6+)** (Lógica do jogo, física, IA e gerenciamento de estado)
- **Three.js (r128)** (Biblioteca de renderização gráfica 3D WebGL)
- **PointerLockControls** (Controles de câmera em primeira pessoa)
